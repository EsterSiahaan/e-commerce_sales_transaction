# 📊 E-Commerce Sales Transaction Analysis using Microsoft Excel

## 📌 Project Overview

This project presents an end-to-end sales analysis of an e-commerce transaction dataset using **Microsoft Excel**. The objective is to transform raw sales data into meaningful business insights through data cleaning, exploratory data analysis (EDA), KPI reporting, and an interactive dashboard.

The project demonstrates how Microsoft Excel can be used as a Business Intelligence (BI) tool to analyze business performance and support data-driven decision-making without requiring programming languages.

---

# 🎯 Business Understanding

## Business Problem

E-commerce businesses generate hundreds or thousands of sales transactions over time. However, raw transaction data alone provides limited business value unless it is analyzed and visualized effectively.

Management needs a dashboard that can monitor sales performance, identify top-performing products, understand customer purchasing behavior, and evaluate payment preferences to support strategic business decisions.

---

## Business Objectives

This project aims to:

- Monitor overall sales performance.
- Analyze sales trends over time.
- Identify top-selling products.
- Evaluate product category performance.
- Understand customer purchasing behavior.
- Analyze customer payment preferences.
- Create an interactive dashboard for business monitoring.
- Support data-driven decision making.

## Dataset Description

This project uses the **Sales Dataset** created by **Ajit Jha** and published on Kaggle.

The dataset contains **1,500 sales transaction records**, where **each row represents one completed customer transaction**.

The dataset is designed for sales analysis and includes transaction information such as order dates, products, product categories, customer types, payment methods, quantities purchased, unit prices, and total sales values.

It is suitable for:

- Sales Performance Analysis
- Exploratory Data Analysis (EDA)
- KPI Reporting
- Customer Behavior Analysis
- Product Performance Analysis
- Interactive Dashboard Development

---

## Dataset Overview

| Information | Description |
|-------------|-------------|
| Number of Records | 1,500 Rows |
| Number of Columns | 13 Columns |
| File Format | Excel (.xlsx) |
| Data Type | Transactional Sales Data |
| Granularity | One row represents one sales transaction |

---

## Dataset Features

The dataset consists of the following columns:

| Column | Description |
|---------|-------------|
| Order_ID | Unique identifier for each transaction |
| Order_Date | Date when the order was placed |
| Year | Transaction year |
| Month | Transaction month |
| Quarter | Business quarter (Q1–Q4) |
| Product_Name | Name of the product purchased |
| Category | Product category |
| Region | Sales region |
| Customer_Type | Customer segment |
| Payment_Method | Payment method used by customers |
| Quantity | Number of units purchased |
| Unit_Price | Price per product unit |
| Total_Sales | Total sales amount for each transaction |
